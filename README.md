## About the Project

ExamNotes AI is a full-stack AI study assistant built for students preparing for exams. A user signs in with Google, enters a topic along with their class or level and exam type, chooses the desired output options, and receives structured study material generated by Gemini.

The project is designed as a complete product workflow rather than a simple AI prompt. It includes authentication, credit-based usage, persistent note history, visual learning aids, PDF export, and online payment for additional credits. The application is deployed and available live on Render.

## Live Demo

**Application:** [ai-exam-notes-generator-ccfh.onrender.com](https://ai-exam-notes-generator-ccfh.onrender.com)

New users receive 50 credits. Each note generation uses 10 credits.

## Features

- Google authentication with protected user routes
- AI-generated exam-focused notes using Gemini
- Detailed notes mode and concise revision mode
- Topic importance and prioritised sub-topics
- Short questions, long questions, and revision points
- Optional Mermaid diagrams and Recharts visualisations
- Personal note history stored in MongoDB
- Downloadable, printable PDFs generated with PDFKit
- Credit balance tracking and server-side credit validation
- Stripe Checkout for purchasing additional credit packs
- Stripe webhook handling for confirmed payments
- Responsive React interface with animated interactions

## How It Works

1. Sign in with Google.
2. Enter a topic, class or level, and exam type.
3. Enable revision mode, diagrams, or charts when needed.
4. The backend validates the request and available credits.
5. Gemini generates content in a strict JSON structure.
6. The result is saved to MongoDB and 10 credits are deducted.
7. Review the generated material, revisit it from history, or download it as a PDF.

## Generated Output

Every response is structured for predictable rendering in the frontend:

- Importance-ranked sub-topics
- Markdown-formatted explanations
- Revision points
- Short and long exam questions
- Mermaid diagram data
- Chart data for visual summaries

This structured output approach makes the AI response useful to both the student and the application UI.

## API Routes

| Method | Route | Description |
| --- | --- | --- |
| `POST` | `/api/auth/google` | Sign in or create a user |
| `GET` | `/api/auth/logout` | End the current session |
| `GET` | `/api/user/currentuser` | Get the authenticated user |
| `POST` | `/api/notes/generate-notes` | Generate and save notes |
| `GET` | `/api/notes/getnotes` | List the user's notes |
| `GET` | `/api/notes/:id` | Get one saved note |
| `POST` | `/api/pdf/generate-pdf` | Generate a PDF download |
| `POST` | `/api/credit/order` | Create a Stripe Checkout session |
| `POST` | `/api/credits/webhook` | Process a verified payment event |

## Run Locally

### 1. Clone and install dependencies

```bash
git clone <your-repository-url>
cd AI-Exam-Notes-Generator

cd backend
npm install

cd ../frontend
npm install
```

### 2. Configure environment variables

Create `backend/.env`:

```env
PORT=5000
MONGODB_URL=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret
CLIENT_URL=http://localhost:5173
```

Create `frontend/.env`:

```env
VITE_FIREBASE_APIKEY=your_firebase_api_key
```

Configure Google sign-in in Firebase and register `/api/credits/webhook` as a Stripe webhook endpoint.

### 3. Start the application

In one terminal:

```bash
cd backend
node index.js
```

In another terminal:

```bash
cd frontend
npm run dev
```

Open the local frontend URL shown by Vite.

## Deployment

The live application is deployed on Render as separate frontend and backend services.

- **Frontend:** build with `npm install && npm run build` and publish `dist`.
- **Backend:** install with `npm install` and start with `node index.js`.
- Add the required secrets to the Render environment settings.
- Configure the frontend to use the deployed backend API URL.
- Set `CLIENT_URL` to the deployed frontend URL.
- Register the deployed Stripe webhook endpoint.
